Maltego – OSINT & Digital Forensics Project

1. Project Overview

This project focuses on Open Source Intelligence (OSINT) and digital reconnaissance using the Maltego tool.

The target domain selected for this project is google.com. The project explores publicly available information and visualizes relationships between different digital entities.

2. Project Objectives

* Understand the fundamentals of OSINT.
* Learn how to use the Maltego tool.
* Perform passive reconnaissance.
* Explore domain-related information.
* Understand relationships between digital entities.

3. Tools Used

* Maltego
* Kali Linux
* Internet Connection

4. Target Information

* Target Domain: google.com
* Assessment Type: Passive Reconnaissance
* Project Category: Cybersecurity / OSINT

5. Methodology

1. Install and open Maltego.
2. Create a new Maltego graph.
3. Enter the target domain.
4. Explore publicly available information using supported transforms.
5. Visualize discovered relationships in the Maltego graph.
6. Document observations and screenshots.

6. Results

The observations and findings from the Maltego investigation will be documented with screenshots.

7. Conclusion

This project provides practical learning experience in OSINT, passive reconnaissance, and digital information visualization using Maltego.
